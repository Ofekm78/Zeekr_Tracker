Shared demo copy of the Zeekr tracker, for other Zeekr owners to look at and give feedback:
https://ofekm78.github.io/Zeekr_Tracker/share/

It is a demo: there is no sign-in and nothing is sent to OneDrive. It opens with an invented year of data
(`demo-data.json`, 1.1.2026 to 31.12.2026, about 2,300 km a month at about 20.8 kWh per 100 km), and anything a visitor adds,
deletes or imports stays only in their browser. Settings has a button that brings the demo data back.
It always opens on the "about" tab, which explains the idea and lists the features.
This copy has no loan tab and no links to the main or trial copies.

`app.js` and `styles.css` are the same files as in `beta/`; which copy is running follows from the address.
`index.html` is this copy's own (demo notice, about tab, demo data panel).
The shared copy is updated like the main page: changes are tried in `beta/` first and copied here
only after Ofek approves.
