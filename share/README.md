Shared copy of the Zeekr tracker, for other Zeekr owners: https://ofekm78.github.io/Zeekr_Tracker/share/

Each user signs in with their own Microsoft account, and their readings are saved in their own OneDrive.
This copy has no loan tab and no links to the main or trial copies.

`app.js` and `styles.css` are the same files as in `beta/`; which copy is running follows from the address.
The shared copy is updated like the main page: changes are tried in `beta/` first and copied here
only after Ofek approves.
