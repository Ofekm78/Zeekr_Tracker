# Logo files

The ZEEKR TRACKER logo, kept here as the master copy. Each design comes as an
editable SVG and a 1024x1024 PNG.

| File | What it is |
|------|------------|
| `logo-black` | Full logo (car, charger and text), white on black. Used for the opening screen. |
| `logo-white` | The same logo with colours swapped: black on white. |
| `symbol-black` | Car and charger only, no text, white on black. Used for the app icon. |
| `symbol-white` | The same symbol, black on white. |

The red tail light stays red in every version. The app's own icon files live in
`icons/` and `beta/icons/`; these files are not loaded by the site.
